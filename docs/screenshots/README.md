# Скриншоти / відео інтерфейсу

Цей каталог містить докази проходження сценарію практичної 3, зняті на
симуляторі iPhone 18 Pro (iOS 27.0).

| Файл | Що продемонстровано |
|---|---|
| `01-home.png` | Головний екран «Прогрес», статистика та успішно завантажена цитата з API |
| `02-milestone-detail.png` | Стековий перехід до деталей етапу та розгорнутий анімований опис |
| `03-history.png` | Журнал епізодів тяги |
| `05-edit-profile.png` | Модальне редагування профілю |
| `06-sos.png` | Екран дихальної вправи SOS |
| `07-sos-trigger-menu.png` | Вибір тригера тяги перед початком вправи |

Додатково перед захистом можна додати `04-note-editor.png` із модальним
редактором нотатки та повторити `01-home.png` на іншому розмірі iPhone для
окремого підтвердження адаптивності інтерфейсу.

Або одне відео (`demo.mp4`, до ~60 с) проходження всього сценарію: створення
профілю → Home → деталі етапу → назад → журнал → нотатка → збереження →
редагування профілю.

Запис відео із симулятора: `xcrun simctl io booted recordVideo demo.mp4`
(зупинити — Ctrl+C).

Після додавання медіафайлів перевірте, що вони відкриваються безпосередньо з
GitHub і не перевищують обмеження розміру файлів репозиторію.
