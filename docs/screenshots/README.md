# Скриншоти / відео інтерфейсу

Цей каталог — місце для доказів практичної 3 (скриншоти або відео проходження
сценарію). Мінімальний набір:

1. `01-home.png` — головний екран (Прогрес) із заповненими даними.
2. `02-milestone-detail.png` — деталі етапу з розгорнутим поясненням.
3. `03-history.png` — журнал тяги (список).
4. `04-note-editor.png` — модальне вікно нотатки.
5. `05-edit-profile.png` — модальне редагування профілю.
6. Два розміри екрана: те саме (наприклад, `01-home.png`) продубльоване для
   iPhone SE і iPhone 16 Pro Max — `01-home-se.png`, `01-home-max.png`.

Або одне відео (`demo.mp4`, до ~60 с) проходження всього сценарію: створення
профілю → Home → деталі етапу → назад → журнал → нотатка → збереження →
редагування профілю.

Запис відео із симулятора: `xcrun simctl io booted recordVideo demo.mp4`
(зупинити — Ctrl+C).
